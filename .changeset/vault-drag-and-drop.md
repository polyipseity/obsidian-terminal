"obsidian-terminal": minor
---

Dragging files or folders out of the vault onto a terminal now inserts their paths. This works from the file explorer, search, backlinks, bookmarks, links and embedded images in notes, and Bases cards. Files dragged from other apps, such as Finder, Explorer or VS Code, are inserted the same way. Paths are quoted for the terminal's shell, and pasted so that Claude Code attaches dropped images. Dragging a tab or selected text over a terminal is no longer swallowed, so a tab can be docked there again. (by [@janah01](https://github.com/janah01))
