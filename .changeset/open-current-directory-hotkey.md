"Open current directory in terminal: Integrated" now has a default hotkey: `Ctrl`+`Shift`+`H`, or `Command`+`Shift`+`H` on Apple devices. You can change it under Settings → Hotkeys. Hotkeys of the current-directory commands no longer reach the shell when pressed in a focused terminal. With no active file, these commands now show a notice. (by [@janah01](https://github.com/janah01))
