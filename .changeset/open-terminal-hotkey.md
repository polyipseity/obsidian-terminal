"Open root directory in terminal: Integrated" now has a default hotkey: `Ctrl`+`Shift`+`H`, or `Command`+`Shift`+`H` on Apple devices. It opens a terminal from anywhere, also from inside a terminal. You can change it under Settings → Hotkeys. Hotkeys you assign to the current-directory commands no longer reach the shell when pressed in a focused terminal. With no active file, these commands show a notice. (by [@janah01](https://github.com/janah01))
