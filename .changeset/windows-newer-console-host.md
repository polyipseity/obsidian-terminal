On Windows, ConPTY terminals run on the console host that ships with Windows Terminal 1.22 or newer when it is installed, which passes more terminal replies to programs, such as the reply that lets a program show its status on the tab. Otherwise they use the console host built into Windows. Turn off "Windows Terminal console host" in the settings to always use the built-in one. (by [@janah01](https://github.com/janah01))
