Terminal tabs can now show the status of the program running in them: working, done, needs input or failed. Programs report it with OSC 7501. With this on, terminal tabs get a prompt icon in two styles and at a size you choose. This is experimental and off by default. Turn it on under `Experimental` in the plugin settings. (by [@janah01](https://github.com/janah01))
